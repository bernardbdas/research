# Security Policy

## Supported Versions

This is an academic research repository. The latest version on the `main` branch
receives active security updates and dependency maintenance.

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive information leakage within this
repository:

1. **Open a GitHub Issue**: Please open an issue in this repository detailing the
   concern, and the maintainer will respond as soon as possible.
1. **Alternative Contact**: In case of urgent concerns or if you do not receive an
   immediate response, feel free to reach out via:
   - **X (Twitter)**: [@bernardbdas](https://x.com/bernardbdas)
   - **LinkedIn**: [bernardbdas](https://linkedin.com/in/bernardbdas)

Please include:

- A description of the issue.
- Steps or proof-of-concept to reproduce the problem.
- Any potential impact or affected files.

Reports will be reviewed and remediated promptly.
